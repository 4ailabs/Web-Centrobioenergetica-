# Sistema de Tipografía - Instituto Centrobioenergética

## 🎨 Fuente Implementada

### Fuente Principal

#### **Inter** - Fuente Única
- **Uso**: Todo el texto de la aplicación
- **Características**: 
  - Excelente legibilidad en pantallas pequeñas
  - Diseñada específicamente para interfaces digitales
  - Amplia gama de pesos (300-800)
  - Optimizada para lectura en pantallas
  - Consistencia visual en toda la aplicación
  - Transmite profesionalismo y confianza
